## Academic-integrity boundary

The implementation is customized around a specific preprocessing split,
candidate grid, API contract, security posture, monitoring metrics, and report
structure. The student should review every component, enter their own identity,
run the workflows personally, explain the choices in the video, and revise any
design choice they cannot defend.
